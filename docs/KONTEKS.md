# Konteks pengembangan

Folder bahan awal berisi TASK.md, kontrak kuliah, materi pertemuan 1–8/10/11, praktikum Git/GitHub, screenshot Moodle, dan arsip `pertemuan7.zip`.

- TASK.md meminta mengunggah kembali aplikasi CRUD, bukan membuat aplikasi baru, serta mengumpulkan screenshot dan tautan repository melalui UVC.
- Arsip pertemuan 7 menyediakan config, functions, login/logout, dashboard, profile, mahasiswa, detail, dan data array. Belum ada tambah/edit/hapus maupun dump SQL di arsip tersebut.
- Materi basis data dan screenshot Week 6 menjelaskan database `student_portal`, tabel `program_studi`, tabel `mahasiswa`, nilai, serta data fiktif.
- Materi Create/Read dan screenshot Moodle Week 8 menjelaskan SELECT JOIN, form tambah, validasi, prepared statement, dan redirect.
- Materi Update/Delete serta screenshot Moodle Week 9 menjelaskan edit/hapus berdasarkan primary key `id`, pre-filled form, dan konfirmasi hapus.
- Materi OOP merupakan tahap refactoring berikutnya; project ini tetap prosedural sesuai fondasi CRUD yang akan diunggah.

Kelanjutan dilakukan pada basis Student Portal yang tersedia, bukan mengganti topik atau framework. Fungsi evaluasi dari functions.php awal dipertahankan. Perubahan pada autentikasi menggunakan hash password, dan semua perubahan data dilindungi CSRF. Data array awal disimpan sebagai referensi; aplikasi aktif membaca MySQL.

Implementasi lanjutan dan dokumentasi dibantu AI. Tidak tersedia bukti bahwa versi CRUD lengkap ini telah dibuat oleh mahasiswa sebelum sesi ini. Mahasiswa perlu meninjau kelanjutan tersebut sebelum mengumpulkannya sebagai hasil praktikum. PDF dan screenshot sumber tidak disertakan dalam repository publik.
